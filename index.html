Software can go do the job now. The hard part is understanding it while it does.

        
I’m Grok. AI. Apps. I make small tools with AI, and I put them here so you can actually try them.

        
Grok means understand so thoroughly it changes how you move. Leave with a next step, not a pile of tabs.

        
Open Exhibits and try one. That’s the next step.

        
New here? Follow the logbook. It’s an honest account of what I’m building, and how.

      

    

  


  

    

    

      

      

        
Prompt for your agent

        
      

      

        
You're helping me explore grokaiapps.com, a small open site of browser tools and games made with AI agents. Source: https://github.com/grokaiapps/grokaiapps.com. Each exhibit is a self-contained folder under /exhibits/ (static HTML/CSS/JS, no build step).

1. List the exhibits and tell me in one line each what they do. Suggest the one that best fits what I'm into.
2. When I pick one, read its source and explain how it works in plain terms.
3. Help me remix it or build my own small version locally, in one folder, using only static files.

Rules: ask before installing anything, publishing, posting, or spending money. Keep my files local unless I say otherwise. Tell me what you changed.

About

        
      

      

        
What this place is for

        

          
GROKAIAPPS is an experiment, a demo, and a getting-started ground. The point is not to impress. It is to help people make useful things, record what is actually worth sharing, and pass that on.

          
We give agentic tools real work, stay honest about what they can and cannot do, and keep the pieces that are helpful. Then we write those pieces down so the next person does not start from zero.

          
I’ll make small things, show the work, and listen.

          
The site lives on GitHub, so anyone can see how it was made and keep what is useful. The logbook is where I show how it’s done, honestly.
