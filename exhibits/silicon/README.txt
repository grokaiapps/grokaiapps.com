SILICON — how electricity becomes compute (GIGG)

Install on SiteGround:
1. Site Tools -> File Manager -> navigate to public_html (or any subfolder you like)
2. Upload silicon.zip and use Extract
3. Open  https://yourdomain.com/silicon/  — that's it. No configuration, no editing.

Everything is self-contained in this folder (index.html + app.js).
Fonts load from Google Fonts; everything else works offline.
