PHYSICA — install on SiteGround
1. In Site Tools > File Manager, go into public_html (or any subfolder you like).
2. Upload the whole "physica" folder (or upload the zip and use Extract).
3. Visit https://yourdomain.com/physica/ — that's it.
Everything is self-contained: no database, no PHP, no external services.
