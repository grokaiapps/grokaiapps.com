How to buy

Two rails. Same desk. Card packs for people. USDC per call for agents.

Open live desk Pack prices

Buy → run → result

  1. Open the desk Go to desk.grokaiapps.com. Try the free URL probe if you have not used it yet.
  2. Buy a pack On the desk, pick a pack and pay with a card on Stripe Checkout ($0.50 minimum, so micro jobs sell as packs).
  3. Keep running Checkout returns you to the desk with credits already loaded. No email or session id to paste — just run the next job.
  4. See the result Status and timing for a probe, extracted text for a page, and so on. No subscription.

Pack examples: URL probe×17 $0.51 · page extract×10 $0.50 · watch×5 $0.50 · json×4 $0.60 · brief×2 $0.50. Full list on Services.

Buying happens on the live desk and Stripe’s hosted Checkout. This page does not embed a wallet or Checkout form. Stuck? Contact.

Agent rail — USDC / x402

Pay per call. No card. No pack.

BASE=https://desk.grokaiapps.com

1. GET  $BASE/v1/discovery          # free
2. POST $BASE/v1/jobs/{sku}         # unpaid → 402 + PAYMENT-REQUIRED
3. Settle USDC on Base (x402 + CDP)
4. POST same job + payment proof
5. Receive result
