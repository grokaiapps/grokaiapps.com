Use Desk from Claude or Cursor

Desk also works as a tool inside AI apps. Add one line to Cursor or Claude Code and your assistant can run any Desk job for you — same prices, paid from your pack credits.

{
  "mcpServers": {
    "autogrok-desk": {
      "url": "https://desk.grokaiapps.com/mcp",
      "headers": { "X-Entitlement-Key": "your-checkout-email@example.com" }
    }
  }
}

Cursor: paste into ~/.cursor/mcp.json. Claude Code: claude mcp add --transport http autogrok-desk https://desk.grokaiapps.com/mcp --header "X-Entitlement-Key: your-checkout-email@example.com"

MCP server (Claude, Cursor, any MCP client)

Remote MCP over Streamable HTTP: https://desk.grokaiapps.com/mcp. initialize and tools/list are free. Tools: url_probe $0.03, page_extract $0.05, watch_once $0.10, json_shape $0.15, brief $0.25, brief_status free.

Pay per tools/call with x402 (USDC on Base): an unpaid call returns isError: true with an x402 v2 PaymentRequired in structuredContent; retry with the signed payload in _meta["x402/payment"] (e.g. createx402MCPClient from @x402/mcp). Or send header X-Entitlement-Key to spend pack credits.

{
  "mcpServers": {
    "autogrok-desk": { "url": "https://desk.grokaiapps.com/mcp" }
  }
}

Card packs over MPP (Stripe Shared Payment Tokens)

Agents with a Stripe Link wallet (or any Machine Payments Protocol client) can buy any pack by card: POST https://desk.grokaiapps.com/v1/mpp/packs/{pack_id}. An unpaid call returns 402 with WWW-Authenticate: Payment method="stripe", intent="charge" and Desk's Stripe profile as networkId. Pay it with a Shared Payment Token and the response carries an entitlement_key (agk.…) that works as X-Entitlement-Key on /v1/jobs/* and on MCP. Send an existing key with the next purchase to top it up. Cards have a $0.50 minimum, so this rail sells packs only ($0.50–$0.60); single calls stay on USDC/x402. Discovery: /openapi.json.

link-cli spend-request create --credential-type shared_payment_token \
  --network-id profile_61VWqT6yAHyjIP6EJA6VWqT668SQipSDos48kYNEeAxc \
  --amount 51 --merchant-name "AUTOGROK Desk" --merchant-url https://desk.grokaiapps.com \
  --context "Buying 17 url-probe credits from AUTOGROK Desk to check link health for the user's site audit." \
  --request-approval
link-cli mpp pay https://desk.grokaiapps.com/v1/mpp/packs/pack_url_probe_17 \
  --spend-request-id lsrq_… --method POST
# → {"entitlement_key":"agk.…","credits":{"url-probe":17}}

Brief promise

Delivered within 24 hours of the order (usually same day). ~500 words by default (max_words 50–1500). At least 3 cited public source links. Result at GET /v1/jobs/:id or MCP brief_status: { title, summary, body_markdown, sources, word_count }. Jobs carry dueBy.
